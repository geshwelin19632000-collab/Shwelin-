AI / TTS API тохиргоо

API key ကို ဒီ HTML ထဲတွင် မထည့်ပါနှင့်။ လျှို့ဝှက် key များကို သိမ်းဆည်းသော backend endpoint တစ်ခုသုံးပါ။ AI endpoint သည် JSON {"action":"translate"|"recap","text":"...","targetLanguage":"my"} ကို လက်ခံပြီး {"text":"မြန်မာစာ..."} သို့မဟုတ် {"translation":"..."} ကို ပြန်ပေးရပါမည်။ TTS endpoint သည် JSON {"text":"...","language":"my-MM"} ကို လက်ခံပြီး audio/* response ပြန်ပေးရပါမည်.

AI ဘာသာပြန်နှင့် server-based TTS အတွက် သင့်ကိုယ်ပိုင် backend/API လိုအပ်သည်။ အသံထွက်အရည်အသွေးသည် browser နှင့် စက်တွင် ရရှိသော မြန်မာ voice များပေါ် မူတည်ပါသည်။
